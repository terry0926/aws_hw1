AWS 網路基礎

作業第六題：可開啟的前端網頁檔案

HTTPS、HTTP 與 Port

  • HTTP：瀏覽器與伺服器交換網頁資料的協定，預設連接埠為 80。
  • HTTPS：HTTP 加上 TLS 加密，可驗證網站身分並保護傳輸內容，預設連接埠為 443。
  • Port：一台主機內用來辨識服務的號碼，例如 SSH 為 22、HTTP 為 80。

Security Group：Inbound 與 Outbound

Inbound 控制哪些來源可進入資源；Outbound 控制資源可連往哪些目的地。設定規則時要指定協定、連接埠、來源或目的地。

Web 伺服器範例：Inbound 允許 TCP 443，來源為 0.0.0.0/0；SSH 22 僅允許管理者的固定 IP。Outbound 可保留預設全部允許，或依需求只開放必要目的地。

CIDR

CIDR 使用「網路位址/前綴長度」表示 IP 範圍。10.0.0.0/24 的 /24 表示前 24 個位元為網路部分，範圍是 10.0.0.0 到 10.0.0.255，共 256 個位址。

DNS、IP、網域與 URL

  • IP：網路上的數字位址，例如 203.0.113.10。
  • 網域名稱：人類容易記憶的名稱，例如 nccu.edu.tw。
  • DNS：將網域名稱查詢成 IP 位址的系統。
  • URL：資源在網路上的完整位置，包含協定、主機與路徑等資訊。

URL 拆解工具

輸入網址後，網頁會將協定、主機、連接埠、路徑與查詢字串拆開說明。
